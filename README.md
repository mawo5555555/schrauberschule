# Schrauberschule

Lern-App (PWA) für Klasse 6 rund um Simson-Mopeds: Werkstatt, Prüfstand, Lackieren, Waschen, Tuning und Schulstoff (Deutsch, Mathe, Englisch, NaWi).
Eigenständige Version 3, getrennt von der älteren App `lernwerkstatt`.

Start: `index.html` öffnet `v2/index.html`. Lokal testen: `python3 -m http.server 8731`, dann `http://localhost:8731/`.
Die Bilder sind KI-erzeugt (Vorlagen: freie Wikimedia-Commons-Fotos und Produktfotos nur als private Referenz, nicht im Repo).
